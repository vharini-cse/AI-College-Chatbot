# AI Chatbot for College Enquiries

## Project Overview

The AI Chatbot for College Enquiries is a web-based application designed to provide quick and convenient answers to common college-related questions.

The chatbot allows students to enquire about important college information such as admissions, courses, fees, hostel facilities, placements, scholarships, and contact details.

## Objectives

- Provide quick responses to common college enquiries.
- Create an easy-to-use interface for students.
- Reduce the need to manually search for basic college information.
- Demonstrate the integration of a web frontend with a Python Flask backend.
- Provide a foundation for future cloud deployment and AI-based enhancements.

## Features

- College enquiry chatbot interface
- Admission information
- Course information
- Fee information
- Hostel information
- Placement information
- Scholarship information
- Contact information
- Interactive chat interface
- Responsive college-style user interface

## Technologies Used
